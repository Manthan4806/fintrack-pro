# FinTrack Pro

A full-stack personal finance management platform built with **React.js, FastAPI, Python, and PostgreSQL**.

## Overview

FinTrack Pro helps users manage their personal finances by keeping track of accounts, transactions, budgets, and spending patterns through an interactive dashboard.

## Features

* 🔐 JWT-based user authentication
* 💳 Account management
* 💰 Income and expense tracking
* 📊 Financial analytics and visualizations
* 🎯 Budget management
* 📈 Income vs. expense analysis
* 🔎 Transaction management
* 👤 User-specific financial data

## Tech Stack

### Frontend

* React.js
* Recharts

### Backend

* Python
* FastAPI
* REST APIs
* JWT Authentication

### Database

* PostgreSQL
